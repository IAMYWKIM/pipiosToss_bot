### 🎯 [프로토콜 A] `8% (12.5분할)` 황금비율 정액제 기반 정량제 (`compute_golden8_quota_qty`) & 자투리 · 실현수익금 실시간 복리 산입

  ▫️ 현재 계좌의 원금 기준 총자산 (`current_total_equity = free_cash_usd + actual_invested_usd`, 단 최소 `initial_seed_usd` 하한 보장) 의 **`8%` ( 12.5분할 )** 인 `portion_budget = round(max(initial_seed_usd, current_total_equity) * 0.08, 4)` 를 산출합니다[span_21](start_span)[span_21](end_span).
🔸 **2️⃣ 직전 기준가 (`anchor_price`) 기반 목표 매수 주수 (`target_qty`) 선행 확정** :
