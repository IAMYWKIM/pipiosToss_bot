🔸 매 스캔마다 직전 확정 분봉(`t-1`, `iloc[-2]`)의 종가(`prev_close`), 평균 상승폭(`prev_avg_gain`), 평균 하락폭(`prev_avg_loss`)을 인메모리 슬롯(`ewm_state`)에 캐싱하고, RSI ≤ 30.0 포착 즉시 소프트웨어 트리거(`wakeup_event`)를 격발합니다.  

💡 2단계: 1.5초 주기 무부하 실시간 틱 RSI 점화식 연산 (`assassin_loop`)  
🔸 메인 스나이퍼 루프는 **1.5초**마다 토스증권 현재가(`current_price`)를 조회하여, 추가 캔들 API 호출(0회) 없이 캐싱된 직전 분봉 기저 상태에 즉시 대입하는 `O(1)` 점화식을 수행합니다.  
  ▫️ **실시간 가격 변화량** : `ΔP = live_price - prev_close`  
  ▫️ **실시간 상승/하락분** : `cur_gain = max(ΔP, 0)` , `cur_loss = max(-ΔP, 0)`  
  ▫️ **Wilder's 평균 상승폭** : `live_avg_gain = (13 / 14) × prev_avg_gain + (1 / 14) × cur_gain`  
  ▫️ **Wilder's 평균 하락폭** : `live_avg_loss = (13 / 14) × prev_avg_loss + (1 / 14) × cur_loss`  
  ▫️ **실시간 틱 RSI 합성** : `RS = live_avg_gain / live_avg_loss` ➡️ `live_RSI = 100 - [ 100 / (1 + RS) ]`  
🔸 이 구조 덕분에 분봉이 확정되기를 기다리지 않고, 프리장 중 단 1초라도 SOXS 가격이 급락하여 실시간 RSI가 30.0 이하에 도달하면 **1.5초 이내에 즉각 지정가 매수 주문**이 발사됩니다.

### 🚨 운용자 절대 주의사항 (마스터 전원 및 수동 오버나이트 통제)  
🔸 **마스터 전원(`🟢 ON`)과 세션 출동 상태의 이해**:  
  ▫️ `/settlement` 제어반의 **마스터 전원(`🟢 ON`)**은 프리장 매수뿐만 아니라 정규장 중 보유 물량의 `+0.64%` 익절 덫 유지, NQ=F 2·3차 손절 덤핑, 15:59 EST MOC 강제 청산을 총괄하는 전체 시스템 전원입니다.  
  ▫️ 따라서 09:30 EST 정규장이 개장하면 마스터 전원은 `🟢 ON`을 유지한 채, **현재 출동상태**가 `🔒 09:30 정규장 신규진입 봉쇄 (관망 · 매수불가)`로 자동 전환되어 신규 매수를 100% 차단합니다.  
🔸 **수동 오버나이트 시 제어반 `🔴 OFF` 필수**:  
  ▫️ 보유 포지션을 15:59 EST에 강제 청산하지 않고 익일로 수동 오버나이트하고자 할 때만, 반드시 **15:59 EST 이전**에 `/settlement`에서 마스터 전원을 `🔴 OFF`로 전환하십시오.  
  ▫️ 마스터 전원이 `🔴 OFF`가 되면 기장전된 지정가 매도 덫이 안전하게 취소되고 MOC 강제 덤핑 및 매크로 손절 루프가 전면 중지되며, 수동 청산 시에도 허위 익절 알림을 보내지 않는 `Silent Reset` 모드로 작동합니다.
